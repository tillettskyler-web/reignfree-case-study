# ReignFree Case Study

Public project summary for [ReignFree](https://reignfree.dev), a custom multiplayer trivia platform built for fast social play.

The active source code is private because ReignFree is a live product. This repository is a recruiter-facing summary of the product thinking, technical scope, and communication work behind it.

## Problem

Trivia tools can be slow to set up, rigid in topic selection, or awkward for groups that just want to start playing. ReignFree explores a more flexible model: hosts create or select a game, share a code or QR link, and players join quickly.

## What I Built

ReignFree is designed for customizable social trivia across friends, classrooms, events, and communities. The product focuses on simple joining, host controls, scoring logic, AI-assisted question workflows, and a mobile-friendly play experience.

## My Role

- Product concept and gameplay design
- Host and player workflow design
- Real-time game flow and scoring systems
- AI-assisted question creation tools
- Content safeguards and quiz structure
- Web app deployment and installable app experience
- Product copy, explanation, and public positioning

## Skills Represented

Product development, game logic, UX design, JavaScript/TypeScript, Supabase, real-time workflows, AI integrations, technical documentation, and user-facing communication.
